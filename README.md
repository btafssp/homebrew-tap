# homebrew-verbamac

Homebrew tap for [VerbaMac](https://github.com/btafssp/VerbaMac), a Latin and Greek dictionary browser for Apple Silicon Macs.

```sh
brew tap btafssp/verbamac
brew trust btafssp/verbamac
brew install --cask verbamac
```

VerbaMac is not notarized; on first launch, approve it in System Settings › Privacy & Security ("Open Anyway").
